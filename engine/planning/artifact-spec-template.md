# Generated Artifact Record Shape

Artifact specification and complete artifact text are authored together in one
forward literary packet. No exact artifact type, title, clue, object, or evidence
family is selected before generation.

```json
{
  "artifact_id": "artifact_01",
  "title": "GENERATED",
  "artifact_type": "GENERATED",
  "physical_form": "GENERATED",
  "provenance_in_story": "GENERATED",
  "claimant_relevance_ids": ["generated_claimant_id"],
  "interpretive_function": "GENERATED",
  "contradiction": "GENERATED",
  "presentation_mode": "inline_expandable",
  "preview_excerpt": "VERBATIM EXCERPT FROM GENERATED BODY",
  "body_mdx": "COMPLETE GENERATED ARTIFACT TEXT"
}
```

Each artifact must plausibly exist, change interpretation, remain readable on mobile,
and behave as evidence rather than decoration. The preview must be a verbatim excerpt;
post-processing may not write or summarize it. Standalone presentation is lawful only
when the generated graph makes the artifact a real route surface.
